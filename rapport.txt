Git est un système de gestion de versions qui permet de suivre les modifications d’un projet.
Il est utile car il garde un historique, permet de revenir à une version précédente et facilite le travail à plusieurs.
GitHub héberge les dépôts Git en ligne et permet de collaborer, partager et suivre les projets.
Dans ce TP, j’ai appris à créer un dépôt, le cloner dans Colab, ajouter un fichier, faire un commit et pousser vers GitHub.
J’ai aussi compris l’intérêt des branches pour développer une fonctionnalité sans modifier directement la version principale.
